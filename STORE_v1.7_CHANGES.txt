OneTime Labs Store v1.7
StreamSafe Real Screenshot Gallery

Changes:
- Replaced all generated / stylized StreamSafe gallery images with real screenshots captured from the application.
- Screenshot images are no longer modified with baked-in annotations or generated callout lines.
- Added a selectable four-screen gallery:
  1. Live Control
  2. Configuration
  3. Status & Logs
  4. Floating DUMP
- Added a crisp HTML/CSS Screen Guide overlay for each screenshot.
- Screen Guide explains the important areas without altering the screenshot itself.
- Added Hide / Show Screen Guide controls so visitors can view the screenshot cleanly.
- Replaced carousel dots with actual screenshot selector cards and thumbnails.
- Gallery now uses object-fit: contain so the real application screenshots are not cropped.
- Full-screen viewer always shows the clean, original screenshot and keeps explanation text in the footer.
- Updated Store package version to 1.7.0.
