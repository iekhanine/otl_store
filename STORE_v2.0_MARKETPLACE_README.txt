ONETIME LABS STORE v2.0 - MARKETPLACE FOUNDATION
=================================================

WHAT THIS RELEASE DOES
----------------------
- Rebuilds the Store homepage so it looks and behaves like a storefront.
- Keeps the existing StreamSafe software product and support work.
- Adds a public Hardware marketplace.
- Adds Store account creation/sign-in for sellers.
- Adds a Seller Center at /seller.
- Sellers can create RAM listings with RAM-specific details and photos.
- Sellers can manage inventory and publish after approval.
- Adds "Sold - Cash" for in-person sales.
  * Records the sale.
  * Allows negotiated cash price.
  * Buyer name/contact are optional.
  * Sale note is optional.
  * No Stripe fee is recorded for a cash sale.
  * Inventory decrements automatically.
  * Listing becomes sold_out at zero inventory.
- Adds Marketplace Admin at /admin.
- Admin can approve/suspend sellers and publish/archive listings.
- Adds seller Stripe Connect fields now, without pretending Connect is wired yet.
- Adds a Stripe live-mode guard so production cannot silently open sandbox checkout.

IMPORTANT: ONLINE HARDWARE CHECKOUT
-----------------------------------
Online hardware checkout is intentionally DISABLED in this build.
The next Store step is Stripe Connect seller onboarding + direct payouts.
Do not enable hardware Buy buttons until Connect is wired and tested.

DATABASE SETUP
--------------
Run:
  sql/004_marketplace_hardware_sellers.sql

This creates:
  store_admins
  store_sellers
  store_listings
  store_sales
  record_store_cash_sale(...)
  store-product-images storage bucket

FIRST ADMIN
-----------
Easiest method:
Set this in Vercel to the email you use to sign into the Store:
  STORE_ADMIN_EMAILS=your-email@example.com

Then redeploy and visit:
  https://store.onetimelabs.net/admin

EMMA FIRST-SELLER FLOW
----------------------
1. Emma visits the Store.
2. Emma clicks Sell.
3. She creates a normal Store account.
4. She creates her seller profile.
5. Her seller status starts as Pending.
6. You open /admin and approve her.
7. She can publish RAM listings.
8. She can still record in-person transactions using Sold - Cash.
9. Next we wire her seller profile to Stripe Connect for card sales/payouts.

STRIPE PRODUCTION CHECKOUT
--------------------------
Store v2.0 expects production Stripe to use a live key.
Set:
  STRIPE_SECRET_KEY=sk_live_...
  STRIPE_STREAMSAFE_PRICE_ID=<LIVE Stripe Price ID>
  STRIPE_WEBHOOK_SECRET=<LIVE endpoint webhook secret>
  STRIPE_REQUIRE_LIVE_MODE=true

If a test/sandbox key is left in production, StreamSafe checkout now fails with
an explicit configuration error instead of silently opening Stripe sandbox.

PRODUCT PHOTOS
--------------
Seller photos use the small Supabase Storage bucket:
  store-product-images

This is appropriate for photos on Supabase Free. StreamSafe's multi-GB installer
will NOT use this bucket. Large software binaries are moving to Cloudflare R2.
